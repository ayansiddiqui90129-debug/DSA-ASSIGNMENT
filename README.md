# DSA Assignment

This repository contains the implementation of the following Data Structures and Algorithms questions:

## Q1. Stack Using Array
Implementation of a stack using an array with:
- PUSH
- POP
- PEEK
- DISPLAY
- Stack Overflow
- Stack Underflow

## Q2. Circular Queue Using Array
Implementation of a circular queue using an array with:
- ENQUEUE
- DEQUEUE
- FRONT
- DISPLAY
- Full and Empty queue conditions

## Additional Tasks
The repository also contains the time complexity, space complexity, and comparison of stack, circular queue, and linear queue as required in the assignment.
